# PCS Path

One checklist for an Air Force PCS move, from out-processing at the losing base
to in-processing at the gaining one.

## Who uses it

| Role | What they do |
| --- | --- |
| **Members** | See their own checklist, with due dates worked out from their departure date. They mark their part done, request appointments and message their sponsor. |
| **Office workers and leads** | Sign members off, confirm appointments, manage time slots and keep their office's hours and status current. |
| **Counselors and commanders** | See who is behind and where tasks are stuck. |
| **Base MPF** | Approves new profiles, maintains the base master list, assigns sponsors and manages roles. |
| **Global admins** | Onboard bases and approve MPF admins. |

When the MPF final-out task is signed, the member's record is released to the
gaining base and their in-processing checklist unlocks.

## Try it

Open `index.html` through a local web server (see SETUP.md) or the GitHub Pages
link. With no database configured it runs in **demo mode**, with fictional
accounts. The password for every demo account is `demo`.

## Use it for real

See **[SETUP.md](SETUP.md)** to connect a free Supabase database and publish
the app with GitHub Pages.

Tasks are adapted from the RAF Mildenhall out-processing checklist. Demo people
are fictional.
